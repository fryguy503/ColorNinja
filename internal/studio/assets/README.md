# Color Pop demo artwork

`color-pop-poppy.png` is an original 1254 × 1254 illustration generated for
ColorNinja using built-in image generation, then edited with the same tool to
make the source fully colored. No external reference image was used.
The PNG is embedded in the desktop app and covered by the project's license.

The demo selects red with sample `#E52A15`, an 8-degree hue range, grayscale
tolerance 8, and an eight-color total palette. The source includes blue sky,
green leaves, blue-violet mountains, turquoise water, and ochre rocks so users
can compare a full-color original with selective desaturation.

## Initial generation prompt

Create one original demo image for ColorNinja, a desktop image-preparation app for HueForge filament art. Square 1024 by 1024 raster illustration, no text, no logos, no watermark, no border. A striking single large scarlet red poppy flower in the upper center-left with a nearly black detailed center, rich red petals with clean distinct shadows and highlights. Graceful stalk and several distinctly green leaves in lower half. Behind it a serene grayscale landscape of gently rolling hills, a gray moon and pale gray sky. Art direction: elegant modern Japanese-inspired woodcut print with broad clean color regions, subtle smooth tonal shading, crisp silhouettes, visually beautiful, optimized for limited-palette printing, avoid grain, noise, speckles, tiny disconnected details. The red flower must occupy about 30 percent of the image and green leaves 15 percent, remaining landscape strictly neutral gray and white. Both rich greens and scarlet reds should be present in source: users will click red to keep the flower colored while converting the green leaves and background to grayscale. Preserve good value contrast so the image also reads well in grayscale. This is a finished standalone illustration, not an app screenshot or mockup.

## Full-color edit prompt used for the shipped asset

Edit this demo illustration to be FULL COLOR throughout. Preserve exactly the composition, large red poppy flower, green stalk and leaves, landscape silhouettes, crisp illustrated woodcut styling, and square format. Keep the poppy rich scarlet red and its center black. Replace the grayscale scenery with a blue sky, a pale cream moon, distant blue-violet mountains, muted green nearer hills, turquoise-blue lake, and warm golden-brown foreground rocks. Keep the colors distinct enough for an image processing demo that preserves red while desaturating all other hues. Use broad clean color regions and reduce fine grain/noise in the landscape; retain tonal shading and silhouette detail. No text, labels, UI, watermark, or border. This is the full-color BEFORE image; do not apply selective desaturation. The full image should look like a beautiful finished color illustration.
