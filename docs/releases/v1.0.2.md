# ColorNinja Studio 1.0.2

ColorNinja now automatically finds the HueForge filament library on macOS,
including Apple Silicon and Intel Macs. When no library has been selected,
startup checks:

```text
~/Library/Containers/com.thehueforge.hueforge/Data/Documents/HueForge/Filaments/personal_library.json
```

Previously, automatic discovery only checked the Windows location, so the
filament list could be empty on a Mac until a library was selected manually.
Windows discovery remains supported. Your saved library selection takes
priority and is remembered across relaunches. Library files remain read-only.

Discovery also ignores missing user directories and folders named as library
files, avoiding accidental detection relative to the application's working
directory. If a saved library is missing, ColorNinja reports the load problem
instead of silently switching to a different filament inventory.

## Validation

Regression tests cover Windows and macOS discovery, first launch, relaunch,
saved-library priority, missing paths, and read-only library handling. Release
checks run on Windows, Linux x64/ARM64, and macOS Intel/Apple Silicon, including
the Go suite, frontend tests/build, vet, dependency audits, and extracted-package
verification.

Packages have no publisher signature; macOS builds are not notarized. Native
window/file-dialog and clean-machine acceptance remains open, including a
manual first-launch check with a real HueForge installation. Software checks
do not establish physical print accuracy.
