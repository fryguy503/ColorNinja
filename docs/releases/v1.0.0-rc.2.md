# ColorNinja Studio 1.0.0-rc.2

Local Windows release candidate focused on Color Match and Color Pop.

- Color Match has a draggable suggested source-color order, arrow controls,
  adjustable preference strength, automatic recalculation, and reset.
- Ordering affects actual matched image heights while respecting color accuracy
  and filament/print constraints. Projects and profiles save the preference.
- New channel workflows are temporarily disabled in the desktop and explicit
  CLI selections. Old channel projects reopen in Color Match with a fresh-preview
  requirement. Their implementation and regression fixtures remain for later.
- Backlit, Color Pop, Simple reducer, Filament Guide, and portable exports remain
  available. See the [color-order guide](../color-order.md).

Validation covers actual-height reorder regressions, zero strength, proportional
weighting, required filaments, neutral groups, invalid inputs, saved projects and
profiles, old-project migration, frontend state, and real-backend browser actions.
The maintained package check exercises both optical models and rejects paused
channel selections. See [production readiness](../production-readiness.md) for
remaining acceptance requirements.

This build is unsigned, comes from a working tree containing development edits,
and is not a published stable 1.0 release. Physical print, clean-machine native
dialog, signing, and external acceptance remain open.
