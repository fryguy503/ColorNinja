# ColorNinja Studio 1.0.0

ColorNinja 1.0 focuses on Color Match and Color Pop for filament stack planning,
with Simple reducer and Filament Guide available for image preparation.

## What's included

- **Drag to reorder colors in Color Match.** Generate a preview, then arrange
  source color groups in **Tune → Color order**, first (bottom) to last (top).
  Adjust **Order strength**, use the arrow buttons with a keyboard or touch,
  or choose **Reset order**. Every edit recalculates, even with Auto preview off.
  Projects and settings profiles preserve the requested order and strength.
- **Color and print constraints remain authoritative.** Ordering scores actual
  matched image heights, including returning filaments, while respecting color
  accuracy, required filaments, base/highlight pins, swap budgets, and depth.
  The preview reports when available blends limit the preferred arrangement.
- **Color Pop and Backlit improvements.** Color Pop supports automatic depth,
  deeper stack refinement, filament constraints, and boundary optimization.
  Front Lit and Backlit outputs retain their lighting and planned heights.
- **Automatic layer placement and depth refinement.** Color Match can favor
  compact accents above surrounding colors and shorten interior runs while
  evaluating the complete blend path.
- **Portable exports.** Save the source, embedded library, options, and exact
  preview in a `.colorninja` project. PNG, layer maps, palette reports, and
  self-contained HueForge projects retain the calculated result.

Standard, Combo, Max Channel, Scaled Max Channel, and Color Aware channel
workflows are temporarily disabled. Their implementation remains available in
the source for future work. Older channel projects reopen in Color Match and
require a new preview; opening leaves the original saved file unchanged.

## Windows download

Download **ColorNinja-1.0.0-windows-x64.zip**, extract it, and run **ColorNinja.exe**.
The GUI requires Microsoft Edge WebView2 Runtime. Python, Go, and Node.js are
not required to run the packaged applications. The ZIP includes the CLI,
documentation, demo artwork, licenses, build/source manifests, and file checksums.
The accompanying `.zip.sha256` file verifies the complete archive.

See the [user guide](../user-guide.md), [color-order guide](../color-order.md),
and [Color Pop guide](../color-pop.md).

## Validation and limitations

Release verification covers 170 Go tests, 13 frontend tests, Go vet, formatting,
the TypeScript/Vite production build, npm and Go dependency audits, real-backend
browser actions, and extracted-package exports in both optical models. It also
checks paused-mode rejection, overwrite protection, portable project/profile
round trips, and SHA-256 integrity. GitHub Actions runs the maintained Windows
verification workflow against the release source.

The Windows executables are **unsigned**. Color ordering is a bounded preference,
so arbitrary requested arrangements may be limited by printable blends and color
accuracy. Software and native-reference tests do not establish physical print
quality for every filament. Physical swatches/held-out prints, clean-machine
native-dialog testing, minimum-spec endurance, and external acceptance remain
open in the [acceptance record](../production-readiness.md).
