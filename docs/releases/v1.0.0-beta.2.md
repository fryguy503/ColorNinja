# ColorNinja Studio v1.0.0-beta.2

This beta adds portable projects, reusable settings profiles, and easier preset
management. Download **ColorNinja-1.0.0-beta.2-windows-x64.zip**, extract the whole
folder, and open **ColorNinja.exe**.

## What's new

- **Portable ColorNinja projects:** save or export a `.colorninja` file containing
  the source image, processing settings, filament library snapshot, and current
  rendered output, including stack and layer data. Reopen it without needing the
  original image or library files. A saved result opens directly without an
  automatic recalculation. Refresh explicitly to calculate with the current engine.
- **Settings profiles alongside exports:** enable **Also save settings profile**
  in the export menu to write a `.colorninja-profile.json` beside each PNG,
  palette report, layer map, HFP, or ColorNinja project export. The profile uses
  the settings that produced that exported result.
- **Presets & profiles:** find these controls directly below Workflow. Create,
  apply, rename, replace, and delete named presets; save and load profile files.
  Presets keep the current workflow by default, with an option to restore the
  saved workflow too. Loading a profile restores its workflow and settings.
- **Batch support:** the CLI adds `--colorninja-project`, `--export-profile`, and
  `--settings-profile` for the same portable project and profile workflows.

Older `.colorninja.json` projects remain readable and still depend on their
referenced files. Saving them again creates a portable project. If settings
haven't been rendered yet, Save project preserves the source and new settings;
the preview is calculated when that project is reopened.

Profiles contain settings and filament filters, rather than image data or a
library. Individual filament exclusions are reused only with a matching library;
the desktop clears them when adapting a profile to a different library.
Portable projects include the full embedded library snapshot.

## Validation and limits

The release gate covers 104 Go tests and eight frontend tests, TypeScript and
production builds, formatting, and Go vet. New checks cover exact source, result,
stack, and metadata round trips after original files are removed; changed library
snapshots; malformed archives; legacy projects; all export/profile combinations;
overwrite protection; preset persistence; and CLI profile reproduction.

Each export file is written atomically. Profile name collisions are checked before
export; if an I/O error prevents the companion profile after the main file was
saved, the app reports which file succeeded. Original images and libraries remain
protected from accidental export replacement.

This is an unsigned portable Windows x64 beta. The desktop needs Microsoft Edge
WebView2; Python, Node.js, and Go are not required. Front Lit predictions and HFP
compatibility retain the Beta 1 limitations, including bounded stack search and
unverified physical print appearance. Broader native-dialog, display-scaling, and
clean-account acceptance testing remains open.
