# ColorNinja Studio v1.0.0-beta.4

Windows x64 beta with a redesigned desktop workspace. Download
**ColorNinja-1.0.0-beta.4-windows-x64.zip**, extract the entire folder, and open
**ColorNinja.exe**.

- A larger image canvas sits beside a focused settings inspector. Tune, Filaments,
  and Layers or Optics organize controls by task; the output dock groups colors,
  selected filaments, and image information.
- File and preset actions, export options, and preferences have dedicated dialogs.
  Advanced controls remain available through the persistent Advanced setting.
- Maximum Filaments defaults to 8 and the main slider supports 1–32. Existing
  budgets above 32 remain usable, with exact budgets available in Advanced.
- All processing modes, library filters, material and TD information, stack and
  optical controls, comparison views, zoom, presets, profiles, portable projects,
  undo/redo, update preferences, and five export formats remain available.
- Export companions and HueForge project settings remain supported, including
  checks that prevent exporting an outdated result.

The [UI coverage document](https://github.com/fryguy503/ColorNinja/blob/v1.0.0-beta.4/docs/ui-redesign.md) maps existing features to their new
locations and records the redesign validation. Packaging includes the desktop
app, CLI, guides, license notices, build information, and SHA-256 checksums.

Validation covers 107 Go tests, eight frontend regression tests, formatting,
TypeScript/Vite, Go vet, and the Windows production build. Browser checks cover
the redesigned controls, saved settings, all export formats, project reopening,
and layouts down to 960 x 720. Packaged desktop and CLI checks verify processing,
preview/export agreement, overwrite protection, and file checksums.

The desktop build is unsigned and requires Microsoft Edge WebView2. Python,
Node.js, and Go are not required. Native Windows file dialogs still need manual
acceptance testing. Front Lit predictions, bounded stack search, and physical
print validation retain the previous beta's limitations. Review output before
printing.

Included downloads:

- `ColorNinja-1.0.0-beta.4-windows-x64.zip`: desktop, CLI, documentation, licenses,
  build information, and per-file checksums.
- `SHA256SUMS.txt`: SHA-256 checksum for the ZIP.
