# ColorNinja Studio 1.1.5

This release fixes the Region Edit drag interruption, speeds up filament order
refinement, and adds optional borders to HueForge exports.

## Region Edit drag fix

Holding and dragging with Lasso or Brush could start the browser's native drag
of previously selected page content, producing a ghost image and interrupting
selection. The editing canvas now suppresses native dragging and text selection.
Space-drag and middle-button panning remain available.

## Faster order refinement

Filament refinement reuses repeated color and boundary-interval calculations
within each candidate. Caches are bounded and private to their palette trial;
the search budget, candidate order, color tolerances and physical blending are
preserved. Regression tests compare the optimized scorer with its original
calculation, including cache saturation and repeated colors at different heights.

On the measured Ewoks configuration, processing completed in about 52 seconds;
the original run was still refining at its 600-second deadline. This establishes
an improvement of at least 11.5× for that configuration, rather than a general
speed guarantee. See the [measurements and limits](https://github.com/fryguy503/ColorNinja/blob/v1.1.5/docs/refinement-performance.md).

## Optional HueForge borders

In **Export → HueForge project (.hfp)**, enable **Add a border**, choose its width
and internal/external placement, then refresh the preview. Match the image's
depth or specify a custom height, including a taller frame that continues the
last filament. The preview reports dimensions, predicted top color, material
estimate and overall print height.

Borders start disabled and persist in projects, profiles, presets and preferences.
Changing a border preserves image pixels, planned layers and Region Edit groups.
HFP exports carry native border settings; PNG and layer-map exports contain the
image only. The rectangular frame does not automatically connect isolated or
transparent artwork. See the [border guide](https://github.com/fryguy503/ColorNinja/blob/v1.1.5/docs/borders.md).

## Validation scope

Release checks cover Go and frontend tests, formatting, TypeScript builds, vet,
dependency audits, browser workflows and extracted packages on all five supported
platforms. Browser regression checks include held lasso/brush strokes over selected
page content, intentional panning, undo/redo, border preview invalidation, HFP
export, reopening and compact layout. Border geometry and taller-frame color/
height fixtures were checked against the installed HueForge 0.9.4.3 native code.

Packages are unsigned and macOS builds are not notarized. Native window/dialog,
clean-machine and physical-print acceptance remain open. Native fixture agreement
does not establish all HueForge mesh backends or physical print appearance.
