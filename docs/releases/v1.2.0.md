# ColorNinja Studio 1.2.0

## Filament library management

- Open **Filament library** from the toolbar in any processing mode. Add, edit,
  duplicate and delete spool entries, including brand, material, color, TD,
  ownership, tags and secondary color.
- External HueForge libraries become a managed ColorNinja copy on the first
  edit. Subsequent saves keep backups, preserve unknown fields, and detect
  conflicting file changes. Export a HueForge-compatible JSON library.
- Unknown TD stays unknown and excludes a filament from stack planning until
  you enter or measure it.

## TD1 / TD1S USB support

- Connect your device, read live TD and color, review recent measurements and
  add a new spool or apply a reading to an existing entry. Replacing its color
  is optional; measurements retain device and time information.
- Use repeated scans with **Save & add another**, export measurement history,
  and view the device's mirrored display.
- Device settings and **Advanced** provide calibration, RGB adjustments, glow
  readings, diagnostics, license handling, device backups/restoration, firmware
  checks and installation, and UF2 recovery with explicit review steps.

See the [filament and device guide](https://github.com/fryguy503/ColorNinja/blob/v1.2.0/docs/filament-management.md)
for connection, measurement and maintenance instructions.

## Import profiles from your browser

- **Import profiles** clearly names **3D Filament Profiles**
  (`3dfilamentprofiles.com`) as the preferred source and opens it in your browser.
- Import copied English detail-page text with its profile URL or numeric ID,
  saved HTML, or exported CSV. Filter imported records locally, review the
  profile, then save it to your library.
- Browser copying can omit buttons and links. The importer accepts this layout,
  including the reported **Anycubic PLA Basic Mia White** page, without inventing
  a TD where none is provided.
- Direct in-app search and URL fetching were removed because the site's access
  checks made them unreliable. There are no retry countdowns. Imports are read
  locally, and library edits and measurements are not uploaded to the website.

## Validation and device coverage

Release checks cover Go and frontend tests, formatting, production builds,
Go vet, dependency audits, compiled-app browser acceptance and extracted
packages. Regression fixtures cover the reported copied-page failure, library
preservation, measured-TD replacement, and TD1 protocol and maintenance handling.

A physical TD1S on Windows was verified for connection, firmware/settings and
backup reads, live TD/color measurement, and applying its measured TD to an
imported profile while retaining the profile color. Original TD1 and native
Linux/macOS USB operation remain unverified. Calibration, settings writes,
license installation, firmware flashing and recovery were not exercised on
physical hardware. See the
[research and validation record](https://github.com/fryguy503/ColorNinja/blob/v1.2.0/docs/td1-research.md)
for the inspected HueForge/TD1 feature coverage and its limits.
