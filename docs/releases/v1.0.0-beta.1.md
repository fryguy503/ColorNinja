# ColorNinja Studio v1.0.0-beta.1

This Windows beta improves image simplification and Front Lit filament planning,
and adds HueForge project export. Download **ColorNinja-1.0.0-beta.1-windows-x64.zip**,
extract the whole folder, and open **ColorNinja.exe**.

## What's new

- **Simpler color reduction:** one total color limit by default, independent
  Off/Gentle/Balanced/Strong smoothing, and detail preservation. Strong smoothing
  remains available with Preserve details off to help clean up splotchy regions.
- **Color priorities:** choose Overall balance, Distinctive colors, or Vivid colors
  to retain important accents while consolidating similar shades. These priorities
  also guide filament selection and stack planning.
- **Front Lit planning:** TD-aware cumulative color predictions, lighting choices,
  and separate first/regular layer heights. Optional filament returns allow an
  earlier spool to appear again later in the stack.
- **Automatic depth:** set a hard maximum such as 4.0 mm, including the base.
  The search prefers the thinnest plan within 1% of its best color score found.
- **Interactive stack map:** inspect physical filament runs, predicted layer colors,
  and mesh targets, with height, material, TD, and actual image coverage per layer.
- **HueForge project export:** save an embedded image and both cores in `.hfp`.
  Color Match with Match planned layers is the recommended starting point;
  additional mesh modes, width, and detail settings are available.
- **Finish filtering:** optionally avoid silk, metallic, pearl, Elixir, and Starlight
  entries in Filament Guide and Global Stack. Library files remain read-only.
- **Desktop improvements:** persistent Advanced controls, exact image color counts,
  GitHub update checks with an optional beta/alpha channel, and corrected Windows
  confirmation when replacing an exported PNG.

## Validation and limits

The release gate covers 97 Go tests, six frontend tests, TypeScript/production
builds, formatting, and Go vet. Package checks cover extracted-file checksums,
source provenance, all three CLI modes, overwrite protection, and matching desktop
preview/export output. See the bundled validation guide for the full test scope.

HFP compatibility was checked with HueForge 0.9.4.3. Color Match preserves the
planned layer assignments; other mesh modes recompute heights. HFP reserves an
unused top layer for import rounding, so its allowed depth can exceed the actual
planned print depth. Mesh resampling can affect fine boundaries.

Stack search is bounded and does not guarantee a global optimum. Color predictions
are not measured print colors; matte and shiny surface appearance is not simulated.
This release focuses on Front Lit. Review projects in HueForge before slicing.

The portable Windows x64 build is unsigned and requires Microsoft Edge WebView2
for the desktop interface. The CLI does not need WebView2. Python, Node.js, and Go
are not required to run either executable. Broader display-scaling, native-dialog,
and clean-account acceptance testing remains open. Updates are installed manually.

ColorNinja is independent and is not affiliated with or endorsed by HueForge.
