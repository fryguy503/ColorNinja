# ColorNinja Studio v1.0.0-alpha.1

The first public alpha of ColorNinja Studio: a local desktop app and CLI for
perceptual color reduction and filament-aware image preparation.

## Download

Download **ColorNinja-1.0.0-alpha.1-windows-x64.zip**, extract it, and open
**ColorNinja.exe**. The archive also includes **colorninja-cli.exe**, documentation,
MIT and third-party licenses, build details, and file checksums.

The desktop app needs Windows x64 and Microsoft Edge WebView2 Runtime. No Python,
Node.js, or Go installation is required to run it. The CLI does not need WebView2.
GitHub's source archives contain the project source rather than the compiled app.

Compare the download's SHA-256 with the release's **SHA256SUMS.txt**:

```powershell
Get-FileHash .\ColorNinja-1.0.0-alpha.1-windows-x64.zip -Algorithm SHA256
```

## Included in this alpha

- Perceptual reduction, filament-guided preparation, and approximate global-stack planning.
- Detail preservation, transparency, full-resolution PNG export, and unique color counts.
- HueForge library import with ownership/material filters, TD, and true-black controls.
- Sliding and side-by-side comparison, linked zoom/pan, auto preview, and cancellation.
- Projects, presets, undo/redo, recent images, JSON palette reports, and 16-bit layer-index export.
- PNG, JPEG, WebP, GIF, TIFF, and BMP input with orientation and supported color profiles.
- A standalone Go CLI using the same image engine as the desktop app.

## Validation and known limitations

Validation passed: **60 Go tests**, **2 frontend regression tests**, frontend
formatting, TypeScript/production frontend compilation, and `go vet`. The Go
suite includes five pixel-exact Python-reference image fixtures. Both Windows
executables compiled successfully. BUILD-INFO.json records the actual build results,
toolchain, source commit, and executable hashes. See
[validation scope](https://github.com/fryguy503/ColorNinja/blob/v1.0.0-alpha.1/docs/validation.md)
for coverage and remaining manual checks.

This is an **alpha prerelease**, with unsigned Windows x64 binaries. Full native
dialog, drag/drop, display-scaling, and clean-account acceptance testing remains
open. An installer, automatic updates, and macOS/Linux packages are not included.

Global stack uses ColorNinja's independent optical approximation. Verify results
in your printing workflow; it does not reproduce HueForge's proprietary engine.
Layer-index PNGs store literal layer counts, not normalized height, STL, or G-code.
Processing uses 8-bit RGBA; HDR/16-bit photo precision is not retained.

For normal HueForge preparation, start with **Filament guided**, export a PNG,
then open it in HueForge to create the final print plan. ColorNinja is independent
of, and is not affiliated with or endorsed by, HueForge.
