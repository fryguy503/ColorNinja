# ColorNinja Studio 1.0.1

Color Match now explores larger changes to layer allocation and keeps an
alternative thickness arrangement for promising filament orders. This lets the
planner escape cases where moving a single layer gives no immediate improvement.
Every trial rebuilds the complete blend path and respects the base, depth,
filament, run, and required-spool constraints.

When an existing surface, material, or layer-order optimization is enabled,
palette selection also compares nearby reachable colors and their print heights.
It can use a slightly different color to improve the enabled objective within
the permitted color error. Search and export share that selection, so the scored
palette is the one exported. No new optimization setting is enabled by default.
Front Lit and Backlit blending equations are unchanged.

Six synthetic two-filament cases that exposed missed layer allocations now reach
their exact target palettes in both Preview and Refine. New regressions cover
depth and filament limits, color tolerances, required heights, cancellation,
determinism, and agreement between search and HFP export. The selected layer colors
also passed local HueForge 0.9.4.3 native blend checks with zero RGB-byte error in
all twelve returned plans. This is software compatibility evidence, not proof of
physical print accuracy or a globally optimal search.

## Native downloads

- Windows x64: `ColorNinja-1.0.1-windows-x64.zip`
- Linux x64: `ColorNinja-1.0.1-linux-x64.tar.gz`
- Linux ARM64: `ColorNinja-1.0.1-linux-arm64.tar.gz`
- macOS Intel: `ColorNinja-1.0.1-macos-x64.zip`
- macOS Apple Silicon: `ColorNinja-1.0.1-macos-arm64.zip`

Every platform is built on a native CI runner from committed source. The release
checks run the Go suite, frontend tests and build, Go vet, dependency audits,
archive checksums, and the extracted application. Linux/macOS package checks run
four CLI workflows and the desktop HTTP service; Windows also runs browser
acceptance against the compiled application. Packages include source identity,
file manifests, third-party notices, documentation, and checksums.

Linux binaries target Ubuntu 24.04 with GTK 3 and WebKitGTK 4.1. macOS packages
are tested on macOS 15. These packages have no publisher signature, and macOS
builds are not notarized. Native window/file-dialog and clean-machine acceptance
on Linux/macOS remains open. On those platforms, convert images with unsupported
ICC profiles to sRGB before importing. See the [installation instructions](../../README.md#download-and-run).

The decompilation projects, executable extracts, dumps, and private research
fixtures are kept outside the repository and release packages. Committed
regressions use synthetic filament data.
