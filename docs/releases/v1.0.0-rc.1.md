# ColorNinja Studio 1.0.0-rc.1

This Windows x64 release candidate completes the additional height workflows
and extends the existing Beta 7 development work. It is a local, unsigned
candidate for acceptance testing, not a published stable 1.0 release.

## Changes

- Standard, Combo, Max Channel, Scaled Max Channel, and Color Aware stack planning.
  Includes both Standard brightness models, mixing, full-range normalization,
  brightness, gamma, inversion, all six RGB orders, per-channel shifts,
  exclusions, band weights and inversions, and boundary gap layers.
- HueForge 0.9.4.3 Backlit optical prediction throughout guidance, stack search,
  rebuilding, physical previews, calibration sensitivity, and HFP export.
- Color Pop and brightness/region workflows share complete-stack refinement,
  bounded automatic-depth search, required/base/highlight constraints, run limits,
  and intermediate-color boundary optimization.
- Desktop controls, CLI flags, saved settings, presets, profiles, comparisons,
  portable projects, and HFP encoding retain each workflow's settings and heights.
- Windows CI, dependency audits, browser acceptance, extracted-package checks,
  signing integration, build provenance, and source-file checksums.

## Verified software behavior

- Native numeric references: 656 brightness cases, 512 Color Aware shifted-channel
  brightness cases, and 300 Backlit stack/light cases, in addition to the existing
  Front Lit reference suite.
- All 14 workflow/lighting exports passed the installed HueForge material reader,
  inclusive run expansion, physical blending, and unmodified Color Match shader.
  Zero physical RGB-byte differences and zero planned-height mismatches over
  **22,015,224 visible pixels** (the same 1,254 × 1,254 demo under 14 settings).
- Portable projects reopen, export identically, and rerender from embedded data
  under every stack workflow in both light models.
- Browser acceptance covers new controls, Backlit, persistence, undo, stale export
  blocking, Escape, and layouts at 1440, 1080, and 960 pixels.
- Full Go tests, Go vet, frontend regression tests, formatting, TypeScript and
  Windows builds pass. The exact counts and binary hashes are in BUILD-INFO.json.
- npm audit and govulncheck reported no known vulnerabilities when checked.

## Scope of these results

Native checks establish compatibility of the tested calculations and exported
height assignments. ColorNinja's stack search, surface-color limits, band
allocation, and neutral placement are its own planning choices. The tests do
not establish identical results from HueForge's complete native mode workflows
or a globally optimal stack. Physical swatches, print acceptance, native dialogs
on a clean Windows account, and external testers remain required before stable
publication. Authenticode integration requires a real publisher certificate.

See [height workflows](../height-workflows.md), [production readiness](../production-readiness.md),
and [calibration](../calibration.md) for usage and acceptance steps.
