# ColorNinja Studio v1.0.0-beta.7

Windows x64 prerelease. Extract the complete
`ColorNinja-1.0.0-beta.7-windows-x64.zip` and run `ColorNinja.exe`.

## Color Pop

- Keep sampled hues and turn the rest of the image grayscale. Pick directly
  from the original, keep up to eight samples, and adjust hue range and
  grayscale tolerance. Selection applies to matching hues throughout the image.
- Inspect a selection mask and compare the original and result using the
  existing preview layouts. Smoothing and palette reduction run separately in
  the color and grayscale regions to preserve accents and neutral backgrounds.
- Try the embedded full-color poppy through **Workflow → Color Pop → Try demo**.
  Red is selected initially; the blue sky, green leaves, and landscape become
  grayscale. The source PNG and generation record are also included in the ZIP.
- **Prepare image** works without a filament library and exports full-resolution
  PNGs with source transparency. Quality metrics compare against the deliberately
  desaturated image.
- Experimental **Plan filament stack** allocates separate brightness-to-height
  bands for color and grayscale. Adjust their height share, order, and boundary
  gap. The planner supports filament returns, neutral grayscale-band materials,
  and the existing filament and surface-color limits.
- Presets, portable projects, undo/redo, comparison snapshots, palette reports,
  PNGs, layer maps, and HFP exports retain the treatment. Plan comparisons vary
  band allocation, run budget, and region order. CLI Color Pop flags use the
  same engine.

## Color Match naming

The former **Global stack** workflow is now **Color Match** throughout the
interface and current guides. Its processing behavior, saved mode identifier,
and `--hueforge-stack` CLI flag stay compatible. Color Pop remains a separate
workflow with its own controls.

## HueForge compatibility and limits

Color Pop HFP exports use Color Match with a virtual Mesh Core to preserve the
planned heights, including identical physical RGB colors at different heights.
Keep the exported mesh mode to retain those bands. The embedded mesh image may
use nearby RGB keys to distinguish heights; physical filament definitions and
the result PNG retain their computed colors.

Both band orders of the 1254 × 1254 demo were checked against installed HueForge
0.9.4.3 native material/blending routines and its unmodified Color Match shader:
zero layer mismatches across 1,572,516 visible pixels and zero byte-level physical
RGB differences. These are software compatibility checks, not physical print
measurements or a guarantee of the best possible stack.

Color Pop selection is based on hue rather than object recognition. The stack
planner uses fixed thickness; ordinary automatic-depth, refinement, and
show-through controls do not apply. Filament RGB/TD and layer order affect the
physical preview, and translucent neutral material can show underlying color.

See the [Color Pop guide](../color-pop.md), [user guide](../user-guide.md), and
[validation notes](../validation.md). The Windows build remains unsigned and
requires Microsoft Edge WebView2 Runtime; the CLI does not require WebView2.
