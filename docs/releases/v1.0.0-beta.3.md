# ColorNinja Studio v1.0.0-beta.3

This beta fixes the export option so it includes a complete, reopenable ColorNinja
project. Download **ColorNinja-1.0.0-beta.3-windows-x64.zip**, extract the whole
folder, and open **ColorNinja.exe**.

## What's changed

- **Also save project and settings profile** writes a reopenable `.colorninja`
  project alongside each PNG, palette report, layer map, or HFP export, as well
  as the reusable settings JSON. An already-checked Beta 2 preference stays on.
- The companion contains the original image, filament snapshot, settings, and
  exact rendered result. Exporting a project does not create a second project.
- Existing companions require separate overwrite approval before exporting.
- **Open project** now recognizes settings profiles and palette reports instead
  of reporting a missing filament library. Its default filter shows project files.

For `artwork.hfp`, reopen `artwork.hfp.colorninja`. Apply
`artwork.hfp.colorninja-profile.json` through **Presets & profiles → Load
profile** when reusing settings on another image.

Re-export existing work with the option checked to create its companion project.
Settings profiles exported by Beta 2 remain reusable; they do not contain an image
or the full filament library needed to restore a complete project.

## Validation and limits

The release gate covers 107 Go tests, eight frontend tests, formatting, Go vet,
TypeScript checking, and the Windows production build. Tests cover all export
kinds, exact restoration and rerendering without original image/library files in
all three modes, overwrite protection, and incorrect JSON imports leaving the
current document unchanged. The packaged app's HFP export and reopen flow also
preserves the HFP bytes and rendered pixels exactly.

Each file is written atomically. Existing companion filenames are checked before
exporting; if a later I/O error prevents a companion, the app identifies the files
already saved. Exporting a ColorNinja project adds its profile without creating a
duplicate project.

This is an unsigned portable Windows x64 beta. The desktop requires Microsoft Edge
WebView2; Python, Node.js, and Go are not required. Front Lit prediction and HFP
compatibility retain the previous beta's limitations, including bounded stack
search and unverified physical print appearance. Broader native-dialog,
display-scaling, and clean-account acceptance testing remains open.
