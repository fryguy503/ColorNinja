# ColorNinja Studio 1.1.0

**Region Edit** lets you draw around many areas and assign them to a layer in
one operation. Open it above a generated Color Match or filament-stack Color
Pop preview, make your edits, then choose Done to return to the normal workflow.

## Region editing

- Select with click, freehand lasso, polygon, rectangle or brush. Choose whole
  enclosed regions, touching regions or exact pixels; add, subtract and intersect
  selections. Zoom and pan while working on fine details.
- Assign a specific layer, sample a layer from the image, or raise/lower selected
  areas while retaining their relief. Printable bounds keep ordinary edits
  within the existing filament stack.
- Grow, shrink, invert and fill selections; select matching layers, similar
  colors and small speckles. Flatten, match surrounding height, smooth, restore
  generated heights or explicitly cut a hole through the base.
- Keep named edit groups with bypass, protection, island splitting and deletion.
  Compare before/after and undo/redo selections and edits.
- Save exact footprints and the original generated plan in portable projects
  and export companions. Edited heights update previews, surface views, quality
  summaries, layer PNGs and HueForge exports, including Color Pop and Backlit.

Processing settings stay in the normal workspace; refinement and cleanup tools
expand only when needed. Existing workflows remain opt-in. See the
[Region Edit guide](https://github.com/fryguy503/ColorNinja/blob/v1.1.0/docs/region-editing.md)
for controls, persistence and limits. Edited projects require 1.1.0 or later;
older projects remain supported. Saved groups persist, while undo history starts
fresh when a project is reopened.

## Printable depth snapping

Base depth and manual maximum depth snap to the nearest printable height when
you finish typing. For a 0.16 mm first layer and 0.08 mm regular layers, 0.86 mm
becomes 0.88 mm. Changes to layer heights also adjust dependent depths and retain
at least one base and one top layer. Automatic depth's maximum remains a hard
ceiling. Command-line and settings-file validation remains strict.

## Validation scope

Tests cover region connectivity, shape coverage, selection refinement, clamping,
protected masks, cuts/restoration, exact project reopening, malformed footprints,
history and stale requests. Export tests cover Color Match, Color Pop and Backlit,
including equal colors at different heights. Browser acceptance runs against
the compiled app for depth entry, selections, undo/redo, zoom/pan alignment,
window sizes and save/reopen/export. The release matrix builds and verifies
extracted packages on all five supported platforms.

Packages are unsigned and macOS builds are not notarized. Native window/dialog,
clean-machine and physical-print acceptance remain open. The editor uses
ColorNinja's own groups; it does not exchange native HueForge Spot Fix groups.
