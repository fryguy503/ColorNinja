# ColorNinja Studio v1.0.0-beta.7.dev.1

Local Windows x64 development package for the Color Match optimization work.
Extract the entire ZIP and run `ColorNinja.exe`. The interface displays this
development version. The package includes the matching CLI and build provenance.

## Appearance and print planning

- **Use the highlight filament only in the final run** prevents an earlier use
  of that spool from capturing foreground colors while permitting other returns.
  Select a required highlight filament to reveal this control under Layers.
- **Reduce printed material** adds an optional area-based planning objective.
  Color fidelity remains guarded by the configured color-score allowance.
- Deeper refinement can relocate a complete run with its thickness and rebuilds
  the optical blend for each candidate.
- Result and comparison cards report estimated solid volume. Exported reports
  also distinguish visible surface area, printing footprint, and buried volume
  for each run. Plan comparisons include a Less material candidate.

Overall appearance remains the review priority. A lower material estimate or
global color error alone does not establish a better print. The new controls
start off and persist in settings, profiles, and portable projects.

## Evaluation

The [optimization overview](../print-optimization.md) includes 21 configurations,
their color and height measurements, visual tradeoffs, and further appearance
work. The exclusive-final-red candidate retains the girl's characteristic colors
and raises her skirt above Totoro; its pronounced relief still needs mesh review.

Engine, CLI, persistence, frontend, and build checks cover the new behavior.
Selected HFPs also passed the installed HueForge 0.9.4.3 native color and layer
mapping checks. These are software checks, not physical print validation.

This is a local development package containing uncommitted changes; it is not a
new GitHub publication. The existing beta.7 release remains separately available.
