# ColorNinja v1.0.0-beta.7.dev.3

Local Windows x64 development build. Published Beta 7 is unchanged.

**Choose depth automatically** now tries shortening interior filament runs after
refining the complete order. Previously, refinement redistributed layers while
retaining total thickness, and the depth search could miss redundant opaque
layers inside the stack. Every trial rebuilds all later blends and rechecks the
color, layer preference, boundary, base, and required-filament constraints.

Boundary scoring now accumulates unwanted intermediate color through the height
interval. The old average could reward repeated endpoint-colored layers by
diluting the score of an unwanted band. Additional opaque layers must now justify
their contribution to the complete result.

On the original Totoro example, the six-layer Navy Blue run reached the same
predicted color on its first layer, with no image pixels assigned to the other
five. The revised Normal preview uses a two-layer Navy base at the required
0.24 mm thickness and selects 2.88 mm total depth. Deeper refinement selects
2.80 mm and uses that base plus one separate Navy return layer. Both compare five
eligible depths and retain the skirt above Totoro. Front-view color and boundary
measurements are in [the optimization overview](../print-optimization.md).

Desktop **HFP export** now always uses HueForge Color Match to preserve planned
heights. The unrelated mesh-mode selector is removed, and older settings,
presets, profiles, cached exports, and reopened projects are corrected. Saved
pixels, heights, and runs are retained. ColorNinja's Color Pop workflow also
exports its planned bands through HueForge Color Match. Explicit legacy CLI
mesh modes remain available.

Validation covers opaque-run shortening without losing subsequent translucent
blends, boundary-score padding, desktop mesh-mode migration, and HFP/project/profile
export consistency. For both full-resolution Totoro exports, the native HueForge
reference reproduced all 17.58 million visible pixel heights and the quantized
physical layer colors. These are software checks, not physical print validation.
